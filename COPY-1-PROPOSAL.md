# COPY-1 Proposal: Public Site Copy Revision Pass

Phase A proposal only: no public site source copy has been changed yet.

The proposed voice shift makes the site sound more like Melissa speaking directly to a customer.
It replaces abstract luxury language with proof of craft: from-scratch baking, buttercream, florals, fruit, piping, and custom quoting.
It keeps The Sweet Fork brand visible, but stops making the brand name do the talking in every sentence.
It softens urgency language into small-batch capacity: Melissa takes a limited number of orders so each one gets attention.
It standardizes every inquiry button as "Request a Quote" so the next step is always clear.
